## How to name branch:
Với mỗi giai đoạn, version thì đặt là
- sprintx-feat:<ten_chuc_nang>/version
ex: sprint1-feat/login/v1
xong nếu có sửa code thì
sprint1-feat/login/v2

## How to write commit code
- Nếu là tạo chức năng mới thì dùng "feat"
- Nếu là sửa code, fix bug thì là "fix"
Cấu trúc commit type(scope): body + footer?optional
Ex: git commit -m "feat(auth): create login API", git commit -m "feat(ui): create login page UI"
